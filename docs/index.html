Work with Your Agent

Facet comes in two parts that install together. Your agentic CLI is the harness: it owns the model, tool calling, permissions, and memory. You describe the outcome; the agent plans the work and calls Facet's tools.

Facet Toolkit

The facet command and the media software it runs. Its tools probe, edit, stitch, compose, narrate, caption, generate, and review video, and its route catalog shows what each production method needs. It never calls a reasoning model and keeps no workflow state. Each tool declares whether it may charge, uses the network, or makes external writes.

Agents reach the tools over MCP with facet mcp. People and scripts run the same tools from the command line.

facet tools list

Facet Bundle

Guidance that teaches your agent to produce video with the Toolkit: the core facet skill, one skill for each of seven production packs, and the facet-creative agent where your CLI supports agents. facet wire installs it into your CLI and connects the CLI to the Toolkit; Claude Code, Codex, and Copilot CLI can also add it as a plugin. Then open the CLI in a production folder and ask:

Use Facet to make a short explainer about how rain forms.

Give the actual file locations when editing existing footage, and review the rendered result.

Facet App

The Facet app is withdrawn in 2.0: the 1.x browser preview did not start from the release installer and has been removed. A Facet App for people who do not use a terminal is planned as a separate download, with Facet's own window, an agent engine, and the Facet Bundle already wired in. Until then, use Facet in your agentic CLI.

Production Packs

Each pack is a skill in the Facet Bundle, named facet-<pack>, with method-specific guidance and supporting content. The core facet skill directs your agent to the relevant pack for the task. Optional tools and providers have their own requirements.

Animated Explainer

facet-explainer

Topic explainers, diagrams, text cards, comparisons, and charts using Remotion.

Requires the Remotion component, which includes the composer, its npm dependencies, and a headless browser. Narration needs a working speech route.

Cinematic & Documentary

facet-cinematic

Montages of supplied, sourced, or generated images and footage, with grading and audio mixing.

Source media must be available and licensed for your use. Generated shots require a separately configured provider.

Screen Demo

facet-screen-demo

Software walkthroughs, supplied screen recordings, and synthetic terminal scenes.

Real product demonstrations need actual screenshots or recordings and access to the app. Synthetic scenes are not evidence of product behavior.

Talking Head & Avatar

facet-talking-head

Presenter scripts, edits to recorded takes, and provider-dependent avatar workflows.

Use supplied presenter footage or an available avatar/lip-sync provider with appropriate consent. Voice synthesis alone does not create a talking face.

Social & Short-Form

facet-social

Vertical edits, podcast highlights, reframing, and captioned clips.

Needs source footage and accurate transcript/timing data for captions. Hook selection and framing still need editorial review.

Character Animation

facet-character-animation

SVG character design, rigs, pose libraries, and authored action timelines.

Requires suitable character assets, rig and animation authoring, and a working renderer. The pack is not a bundled character-generation model.

Localization & Dubbing

facet-localization

Translated voiceovers, subtitle timing, and localized exports of existing videos.

Needs source media, transcription/translation, and a supported target-language voice. Voice cloning and lip-sync need separate providers and consent; language review remains necessary.

Recommended Installation

Install Facet once for your user account, then wire it into the agentic CLIs you use: OpenCode, Codex, Claude Code, GitHub Copilot CLI, or Compa.

Paste the command for your platform into a terminal. It downloads and checksum-verifies the installer package, then starts setup.

Windows (PowerShell)

irm https://kayiik.github.io/facet/install.ps1 | iex

Linux / macOS

curl -fsSL https://kayiik.github.io/facet/install.sh | sh

The installer puts the runtime under ~/.facet/runtimes/, verifies it with short test renders, activates it as ~/.facet/current, and adds ~/.facet/current/bin to your user PATH. Opt out of the PATH change with -NoPath on Windows or --no-path on Linux and macOS. Set FACET_HOME to use another folder instead of ~/.facet. Installation details

On Windows, the installer builds facet.exe on your computer from the release's source with the official Go toolchain, then deletes Go again. It takes a minute or two longer. Why, and how to install offline

Wire Your CLI

Wiring is your decision, like installing a skill or plugin. The installer offers it at the end of setup, or you can run facet wire later. It installs the Facet skills into your CLI's own folders, registers the facet MCP server through the CLI's own configuration, and, where the CLI has a per-tool setting, adds a rule to ask you before each tool that may charge. It never edits instruction files such as AGENTS.md or CLAUDE.md.

facet wire <cli>
facet wire --status

Use opencode, codex, claude, copilot, compa, a comma-separated list, or all, then start a new session in that CLI. Wiring options

Or Add the Plugin

Claude Code, Codex, and Copilot CLI can add Facet from its plugin marketplace once the Toolkit is installed. In Claude Code, run claude plugin marketplace add kayiik/facet, then claude plugin install facet@facet. Use the plugin or facet wire for a CLI, not both. Plugin commands for each CLI

Upgrading from 1.x

In each project that used the 1.x installer, run the v1.1.0 installer with --action uninstall (-Action uninstall on Windows). Then install 2.0 and run facet wire. facet doctor lists 1.x files left in the current or home folder. Upgrade details

Production Runtime

FFmpeg and FFprobe are required; the installer adds them with winget, Homebrew, or apt when they are missing. The default setup installs Remotion and Piper into the runtime; HyperFrames is an optional component. Edge TTS is built into Facet and is preferred for narration when network processing is acceptable.

Generation providers are optional and use your own API keys; gflow is a separately supplied CLI. Provider keys

Using Facet with Another Agent

Using a different agent? Facet's tools are served over MCP by facet mcp, and its skills are plain Markdown. Ask your agent to inspect this repository and adapt the skills and the MCP server registration to its own conventions. facet wire supports the five CLIs listed above; other integrations are community-adapted and may need additional setup.

What to Know Before Producing

  • Generation is conditional. Provider credentials, browser sessions, quotas, and supported models can prevent a request from completing. Errors are not replaced with mock media; explicit mock mode is for testing, not delivery.
  • Paid tools ask first, through your CLI. Eight tools may charge. facet wire adds a rule to ask before each of them in Claude Code, Codex, OpenCode, and Compa; Copilot CLI asks before every Facet tool that is not read-only. Facet declares effects but does not enforce consent, and unknown cost is not free. A paid call cut off midway may already be charged; Kling and Sora calls report a job id that collects the result without a second submission. Read about paid tools.
  • gflow is optional and separately supplied. The public Facet installer does not distribute its private provider dependency. Its help and errors explain the requirements of the provider you configure. Read about gflow.
  • Review is still your responsibility. Check the actual video, audio, captions, and asset rights. There is no fixed-turn, completion-time, or broadcast-quality guarantee.
For Integrators: Technical Reference

Use facet tools list and facet tools describe <name> to inspect your installed build, facet routes list to see the production methods, and facet doctor to check dependencies. Registry entries and schema files are not proof of provider availability or an exhaustive compatibility contract.
